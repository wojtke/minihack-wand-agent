Fixed terrain per level; some placements vary in Hard and Pro. Full maps are revealed for illustration. Limits count all inputs, including menu replies.

MiniHack is built on the NetHack Learning Environment (NLE). All four clips are genuine recordings from the same frozen agent. Easy, Medium and Hard show complete successful episodes. Pro shows only the first 60 decisions of an episode; no success is implied. Playback is accelerated and the camera follows the player using only public game pixels. The labelled icons are cropped directly from native game renders. The four pictures are native game renders with terrain revealed in separate presentation-only instances. The agent and live game never receive these revealed views. Easy and Medium have fixed placements. Hard varies the player and wand positions in the starting area; Pro varies the wand position. Hard and Pro have an awake minotaur. MiniHack sets the default action limits to 50, 150, 400 and 1000. Reaching the limit ends the episode without success.

Easy: a successful wand attack

The policy chooses a discrete action index, which the environment maps to a keyboard input. The eight direction keys are k, l, j, h, u, n, b and y. The three other keys are comma (pick up), z (zap) and f (fire). During a prompt, the same key can select an inventory item or an aiming direction. In the example inventory the wand has letter f; z, f, l therefore means start using a wand, select it, then aim east. Moving into a monster can attack it. These are native single inputs, not scripted multi-step actions. The map is exposed as 21 by 79 arrays of glyph IDs, characters and colours. Other fields include inventory names and letters, game messages and character statistics. The pixel image is a rendering of this observation. Remembered terrain does not provide current information about unseen monsters. The quoted aiming prompt is an example from wand use, not a message from the pictured initial Pro state. These are native MiniHack/NLE rewards with no training bonuses. A frozen-step penalty of −0.01 is added whenever the game clock is unchanged, including menu interactions; this may also happen on a terminal step. The images are before and after the same recorded Easy episode. The last action kills the minotaur and earns +1. On Medium, Hard and Pro, killing the minotaur alone is not the success condition: the agent must reach the staircase.

Move / aim

The live demo runs the original NLE engine in the browser, with the MiniHack task rules and native inputs. Hints are off by default and only explain controls; they do not perform actions. WASD moves north, west, south and east; Q/E/Z/C are diagonals. Arrow keys also work. P picks up, R starts wand use, and F fires or selects the wand during its inventory prompt. Space restarts the current level with the same seed; New game advances the seed. These browser shortcuts map to the same native inputs and do not change the agent’s action space. Press Escape to return keyboard control to the slides.
