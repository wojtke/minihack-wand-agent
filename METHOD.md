# Minimal shared-agent baseline

- **Environment:** the four unmodified `MiniHack-WoD-*-Restricted-v0` tasks. Their native limits are 50 / 150 / 400 / 1,000 inputs. Success is killing the minotaur on Easy and reaching the staircase on the other levels.
- **Actions:** 11 primitive inputs, in native order `kljhunby,zf`. Menus reuse these inputs. There are no action masks, routes, scripted action sequences or difficulty labels supplied to the network.
- **Features:** 463 values from public observations: a 9 × 9 local crop with five channels; nearby visible monsters; remembered objects and exits; inventory letters; health; elapsed actions; current/previous prompt mode; previous input and command. Memory resets each episode. No hidden engine state, full-map reveal or hand-coded paths are used. The encoder is deliberately kept compatible with the included checkpoint. It is engineered for the MiniHack interface, not a raw-pixel learner; it has limited memory and cannot represent an arbitrary large map completely.
- **Algorithm:** Double DQN, two ReLU layers of width 128, Adam, Huber loss, clipped gradients, uniform replay and a hard target-network update. Four environments are stepped in round-robin order, so each receives one quarter of the total action budget. Exploration is independent epsilon-greedy; no curriculum or per-level policy.
- **Training reward:** native reward plus 0.01 for a first visit to an observed player position within the episode, capped at +2 per episode. The initial position earns nothing. No bonus is paid on terminal steps. `--no-bonus` disables it. Native return and bonus are logged separately.
- **Episode ends:** success, death and the native action limit all stop Bellman bootstrapping. This treats each level as a finite-horizon task. NLE's public screen is copied before timeout cleanup; actions, native rewards and limits are unchanged. The hook is specific to pinned NLE 1.1.0 and covered by native tests.
- **Seeds:** training reset seeds are sampled below 100,000,000, using separate seeded streams per level. Evaluation defaults to consecutive seeds starting at 100,000,000; its output includes every episode. Use a separate validation range for tuning and reserve another range for the final test. Report multiple training seeds when comparing methods.
- **Evaluation:** deterministic greedy actions, native rewards only, per-level wins, returns, lengths and Wilson 95% intervals. Test seeds vary game randomness/placements within the four native terrains; they do not create unseen maps.

The supplied config has only been smoke-tested as a runnable learning baseline. No strong success-rate claim is made for a fresh run. The bundled checkpoint predates this simpler trainer and used a longer, multi-stage experimental procedure. Its performance must not be attributed to this config.
